Privacy Policy

Effective July 28, 2026

Overview

Negative Film Viewer is a browser-based tool that converts photos of photographic negatives into positive previews. The tool is designed to operate locally in your browser.

Photos and image processing

When you select a photo, the image is read and processed on your device using browser features. The app does not intentionally upload the selected photo or the converted image to the app operator or to an application server.

The image remains available only in the current browser session unless you choose to save or share the converted result using your device.

Information collected by the app

The app operator does not use accounts, advertising, analytics, tracking pixels, contact forms, or payment systems. The app does not intentionally collect names, email addresses, precise location, photo contents, device identifiers, or usage profiles.

GitHub Pages hosting

This site is hosted by GitHub Pages. GitHub states that it logs a visitor's IP address for security purposes when a GitHub Pages site is visited. GitHub may also process technical and website usage data under the GitHub General Privacy Statement.

The app operator does not control GitHub's hosting logs or privacy practices. Review GitHub's privacy documentation for details.

  • GitHub Pages data collection information
  • GitHub General Privacy Statement

Data retention and deletion

The app operator does not maintain a database of selected photos, converted images, or user activity. Because the app operator does not retain this information, there is no app-held image data to request or delete.

Files that you save or share are controlled by you and by the destination you select.

Third-party services

The current app does not include third-party advertising, analytics, cloud image processing, or social-login services. GitHub Pages is the hosting provider.

Children's privacy

The app is a general-purpose image utility and is not directed specifically to children. The app operator does not knowingly collect personal information from children through the app.

Changes to this policy

This policy may be updated if the app's features, hosting, or data practices change. The effective date at the top of this page will be revised when material changes are published.

Contact

Questions about this policy can be submitted through the Negative Film Viewer GitHub repository issues page.
